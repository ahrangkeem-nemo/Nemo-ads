## 1. 개요

### 1.1 목적
광고주가 광고주센터에서 카카오 모먼트 캠페인 소재를 직접 등록하고, 광고운영 매니저의 검수를 거쳐 카카오 모먼트에 발송 대상으로 셋팅되기까지의 운영 기준을 정의합니다.

### 1.2 적용 범위
- 광고주센터에서 셋팅하는 **카카오 모먼트 캠페인**의 소재
- 소재 등록, 검수 요청, 검토 완료/반려, 재요청, 카카오 모먼트 연동, 캠페인 진행 및 종료

### 1.3 전체 프로세스 요약
```
[광고주] 광고주센터에서 캠페인·소재 셋팅
   ↓ 소재 검수 요청 (광고주 → 광고운영 매니저)
[상태] 소재 검수중
   ├─ 운영 매니저 승인 → [상태] 소재 검토 완료
   │     ↓ 소재 데이터 자동 이동
   │   [카카오 모먼트] 소재 검수 → 발송 대상 셋팅
   │     ↓ 노출 시작 시점 도달
   │   [상태] 캠페인 진행 중
   │     ↓ 노출 기간 경과
   │   [상태] 캠페인 종료
   │
   └─ 운영 매니저 반려 → [상태] 소재 검토 반려
         ↓ 소재 수정 요청 (광고운영 → 광고주)
         ↓ 광고주 수정 후 재요청
       [상태] 소재 검수중 (재검수)
```

## 2. 용어 정의

| 용어 | 정의 |
|---|---|
| 광고주센터 | 네모의 셀프서브 광고 관리 플랫폼. 캠페인·소재·계약·정산을 관리 |
| 카카오 모먼트 | 카카오 광고 플랫폼. 검토 완료된 소재가 자동 연동되어 실제 발송이 이루어지는 곳 |
| 캠페인 | 광고 집행 단위. 소재, 타겟, 예산, 노출 기간을 포함 |
| 소재 | 실제 발송되는 광고 콘텐츠. 타이틀, 홍보문구, 버튼, 타겟으로 구성 |
| 광고운영 매니저 | 네모 측 소재 검수 및 운영 담당자 |
| 광고 예산 | 캠페인의 **최대 발송 건 수** (예: 100건) |
| 검수 | 광고운영 매니저가 소재의 적합성을 확인하는 절차 |
| 반려 | 소재가 기준에 맞지 않아 수정이 필요하다고 판단된 상태 |

### 2.1 객체 구조
- 광고그룹 > 광고상품 구조이며, **광고상품 : 소재 = 1 : 1**
- 결제완료 상태는 **광고그룹 단위**로만 표시됩니다.
- 결제가 확인된 이후에만 캠페인이 집행됩니다.

### 6.1 전환 원칙
- 검토 완료와 반려는 **광고운영 매니저만** 처리할 수 있습니다.
- 캠페인 진행 중·종료 전환은 **노출 시점 기준으로 자동** 처리됩니다.
- 반려된 소재는 수정 후 재요청 시 다시 **소재 검수중**으로 돌아가며, 반려 횟수 제한은 `[TBD]`입니다.
- 결제가 확인되지 않은 광고그룹의 캠페인은 노출 시작 시점이 되어도 집행되지 않습니다.

## 7. 검수 정책

### 7.1 검수 절차
1. 광고주가 검수 요청하면 광고운영 매니저에게 요청이 전달됩니다.
2. 광고운영 매니저가 소재 구성 요소(타이틀·홍보문구·버튼·타겟)를 검토합니다.
3. 적합하면 **검토 완료**, 부적합하면 **반려**와 함께 수정 요청을 보냅니다.

## 8. 카카오 모먼트 연동

- 소재 검토 완료 시 소재 데이터가 카카오 모먼트로 **자동 이동**됩니다. 광고주의 별도 조치는 필요하지 않습니다.
- 카카오 모먼트에서 소재 검수 후 **발송 대상 셋팅**이 완료됩니다.
- 노출 시작 시점에 도달하면 발송이 시작되고 상태가 **캠페인 진행 중**으로 바뀝니다.

## 9. FAQ (챗봇 응답용)

**Q. 소재 검수 요청은 어떻게 하나요?**
A. 광고주센터에서 캠페인을 셋팅하고 타이틀, 홍보문구, 버튼, 타겟을 입력한 뒤 미리보기를 확인하고 검수 요청을 누르면 됩니다. 요청 후 상태가 '소재 검수중'으로 바뀝니다.

**Q. 지금 상태가 '소재 검수중'이에요. 언제 끝나나요?**
A. 광고운영 매니저가 소재를 검토하고 있습니다. 검토가 끝나면 '소재 검토 완료' 또는 '소재 검토 반려'로 바뀝니다. 검수 소요 시간은 `[TBD]` 입니다.

**Q. 소재가 반려됐어요. 어떻게 해야 하나요?**
A. 광고주센터에서 반려 사유를 확인하고 소재를 수정한 뒤 다시 검수 요청해 주세요. 재요청하면 상태가 '소재 검수중'으로 바뀌고 다시 검토가 진행됩니다.

**Q. '소재 검토 완료'인데 광고가 아직 안 나가요.**
A. 검토 완료된 소재는 카카오 모먼트로 자동 이동되어 카카오 측 검수와 발송 대상 셋팅이 진행됩니다. 설정하신 노출 시작 시점이 되면 '캠페인 진행 중'으로 바뀌며 발송이 시작됩니다. 결제가 확인되지 않은 경우에도 집행되지 않으니 광고그룹의 결제완료 여부를 확인해 주세요.

**Q. 광고 예산은 어떻게 설정하나요?**
A. 광고 예산은 금액이 아니라 최대 발송 건 수로 설정합니다. 예를 들어 100건으로 설정하면 최대 100건까지 발송됩니다.

**Q. 캠페인은 언제 종료되나요?**
A. 설정한 노출 기간이 지나면 자동으로 '캠페인 종료' 상태로 바뀝니다.

**Q. 검수 중이거나 진행 중인 소재를 수정할 수 있나요?**
A. `[TBD]` — 현재 정책 확정 전으로, 광고운영 매니저에게 문의해 주세요.

| 상태 | 핵심 메시지 | 안내할 행동 |

### 10.3 운영 매니저 연결(에스컬레이션) 조건
- 반려 사유가 이해되지 않거나 이의를 제기하는 경우
- 검수 요청 후 SLA를 초과한 경우 `[TBD]`
- 검토 완료 후 노출 시작 시점이 지났는데 캠페인이 진행되지 않는 경우
- 카카오 모먼트 측 반려 관련 문의
- 결제·정산 관련 문의
- 본 문서로 답할 수 없는 모든 문의
